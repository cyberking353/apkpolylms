CSV Format

First row must be the header. Column names are case-insensitive. Extra columns are ignored.

first_name,last_name,email,matric_number,department,academic_level
Amina,Bello,a.bello@alhikma.edu.ng,CS/ND1/001,CS,ND1
Yusuf,Sani,y.sani@alhikma.edu.ng,EE/ND1/002,EE,ND1
Hauwa,Idris,h.idris@alhikma.edu.ng,BA/ND2/001,BA,ND2

Rules

  • first_name, last_name, email are required — rows missing these are skipped.
  • If an account with the same email already exists it is skipped (not overwritten).
  • Password is set to the matric_number value. If blank, defaults to alhikma2026.
  • Students are auto-enrolled in matching courses immediately on creation.
  • department must be one of: CS, EE, ME, BA, SLT, ACC, MC, OTH
  • academic_level must be one of: ND1, ND2, HND1, HND2
